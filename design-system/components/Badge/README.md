# Badge

Selo curto em caixa alta para status de produto.

**O consumidor fornece:** `children` (1–2 palavras) e `tone`.

- `ink` — "Novo", "Exclusivo". `sale` — só desconto ("-20%", "Oferta"). `neutral` — origem/atributo ("Importado", "Atacado"). `success` / `warning` — estoque.
- No máximo um selo por cartão de produto, no canto superior esquerdo da imagem.
- A cor nunca é a única informação: o texto diz o status.
