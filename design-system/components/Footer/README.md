# Footer

Rodapé preto (`surface-inverse`) com a logotipo branca, frase de apoio, colunas de links e linha legal.

**O consumidor fornece:** `columns` (`{title, links}` — 3 ou 4 colunas), `tagline`, `legal` (© + CNPJ quando houver), `note`.

- No tema escuro o rodapé inverte para claro e a logo volta a ser a preta.
- Inclua CNPJ, endereço e formas de pagamento na linha legal quando o site for ao ar.
