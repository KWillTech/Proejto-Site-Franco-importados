# Icon

Ícone de traço fino (1.5px, terminações retas) em grade de 24px que herda a cor do texto (`currentColor`).

**O consumidor fornece:** `name` (um dos 12 do conjunto), `size` (padrão 20) e `label` quando o ícone está sozinho e tem significado.

- Use dentro de botões, cabeçalho, alertas e cartões. Cor = cor do texto ao redor (`ink`, `on-brand`…).
- Ícone sozinho num botão: o botão leva `aria-label` ("Buscar", "Sacola, 2 itens").
- Os mesmos desenhos existem como SVG no grupo de assets **Icons**, para uso fora do React.
