# SectionHeading

Cabeçalho de seção da vitrine: sobretítulo em caixa alta, título serifado e link "Ver todos" à direita, sobre um fio `line`.

**O consumidor fornece:** `title`, `eyebrow` opcional e `action` (`{label, href}`).

- Use antes de cada grade de produtos ou bloco de conteúdo. `space-8` entre ele e o conteúdo.
