# Alert

Mensagem de status em linha: ícone + título + texto, com fundo suave e borda na cor do tom.

**O consumidor fornece:** `tone`, `title`, `children` (uma frase) e opcionalmente `icon`.

- `success` confirmações, `info` frete e regras de atacado, `warning` estoque/prazo, `danger` erros de pagamento ou formulário.
- Sempre com título em palavras — a cor nunca é a única pista.
